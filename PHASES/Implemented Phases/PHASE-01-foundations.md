# Phase 01 — Foundations

**State:** implemented · commit `40ae0a3`

Everything the tool needs before a model is involved: turning a coordinate into
a place, knowing what a country looks like, and reading what a file claims
about itself.

---

## Goal

Make a coordinate mean something without a network, and establish the stance on
embedded metadata before any code depends on it.

## What was built

**`mapify/geo/offline.py`** — reverse geocoding from Natural Earth (public
domain). Pure-Python even-odd ray casting over the shapefile rings, which
handles multi-part countries and interior holes without a geometry engine. A
coordinate resolves to a country, a first-order administrative division, and
the nearest populated places.

The gazetteer indexes **all 30 localised name fields** Natural Earth carries,
not just `NAME`. That decision is what later lets a Cyrillic or Bengali sign be
matched without a transliteration step:

```
Москва      -> Moscow    (NAME_RU, Russia)
東京         -> Tokyo     (NAME_ZHT, Japan)
القاهرة      -> Cairo     (NAME_AR, Egypt)
বেঙ্গালুরু  -> Bengaluru (NAME_BN, India)
```

**`mapify/geo/nominatim.py`** — a client that enforces the OpenStreetMap usage
policy rather than trusting call sites to: identifying User-Agent, a one
request per second floor held by a lock shared across threads, an on-disk
cache, and a budget per analysis so one image cannot fan out into a crawl.

**`mapify/exif.py`** — reads embedded GPS and treats it as a *claim*. Returns
it in its own provenance class, never merged into an estimate, with the tamper
signals that can actually be checked: Null Island, a `MANUAL` processing
method, editor software tags, coordinates rounded to ~100 m on both axes, a
non-WGS-84 datum, and capture times that differ from GPS time by more than any
real time zone offset.

**`mapify/data/country_attributes.json`** — driving side, signage scripts,
signage languages and plate class for every country, generated by joining
hand-maintained tables of public facts onto the Natural Earth country list.

## What went wrong

Point geometries carry no `bbox` attribute, so the bounding-box index that
works for polygons threw on the populated-places layer. Derived from the points
instead.

## Left open

- Boundaries follow the Natural Earth default point of view. Disputed areas
  are flagged in the report rather than resolved, because resolving them is not
  this tool's call to make.
- Admin-2 (county/district) is not loaded. Nominatim covers it when allowed.
